# Kelly Jao D. Quidit | Portfolio

This is my personal portfolio website. I'm Kelly Jao D. Quidit, an aspiring network engineer, and I'm studying for a BS in Information Technology (Network Design and Management) at Nueva Vizcaya State University.

🔗 Live: https://redsaucce.github.io/programmers-portfolio/ (preview; will switch to the Vercel production URL once that is ready)

I built it with plain HTML, Tailwind CSS v4 (compiled with the Tailwind CLI), and vanilla JavaScript. There is no framework. Node.js is needed once to install Tailwind and build the stylesheet (`css/tailwind.css`); after that, the site is plain static files.

| Page | File | What it shows |
|---|---|---|

| Projects | `projects.html` | Project cards with tech stack, GitHub, and live demo links |

## Features

- Responsive layout (mobile first), with a full-screen slide-in menu on mobile
- Light and dark mode, remembered between visits, with no flash on load
- Shared navbar and footer defined once (`components.js`) and used on every page
- Icons without an icon library: six repeated icons are defined once in `icons.js` and used as `<site-icon name="user">`; the ten single-use icons are inline SVGs
- Staggered entrance animations and scroll fade-up (turned off for reduced-motion users)
- Accessible basics: skip link, keyboard-friendly menu with a focus trap and Escape to close, visible focus styles, alt text on every image (lazy-loaded), aria labels on buttons and navigation, project-specific link names, and a screen-reader hint on links that open in a new tab

## Tech stack

- HTML5, CSS, and vanilla JavaScript (no framework)
- [Tailwind CSS](https://tailwindcss.com/) v4 (`tailwindcss` and `@tailwindcss/cli`, 4.3.3), compiled from `css/input.css` into `css/tailwind.css`
- [Lucide](https://lucide.dev/) icon paths, inlined as SVG (shared ones in `js/icons.js`, the rest written directly in `components.js` and `about.html`); no icon library or CDN script is loaded
- Plus Jakarta Sans (headings) and DM Sans (body), installed via npm (`@fontsource/plus-jakarta-sans`, `@fontsource/dm-sans`) and bundled into `css/tailwind.css`

## Run it locally

1. Download or clone the project.
2. Install [Node.js](https://nodejs.org/) (LTS), then run `npm install` in the project folder.
3. Build the stylesheet: `npm run build`. This creates `css/tailwind.css`, with the fonts bundled in. Without it, the pages have no styling and no custom fonts.
4. Copy the font files next to the stylesheet (one time, or whenever `node_modules` changes):
   ```
   xcopy node_modules\@fontsource\dm-sans\files css\files\ /E /I
   xcopy node_modules\@fontsource\plus-jakarta-sans\files css\files\ /E /I
   ```
   (macOS/Linux: `cp -r node_modules/@fontsource/dm-sans/files css/files/` and the same for `plus-jakarta-sans`.) `css/tailwind.css` expects the font files at `css/files/`; without this step the fonts 404 and the browser falls back to a system font.
5. Open `index.html` in a browser.

While editing, run `npm run dev` in a terminal. It rebuilds `css/tailwind.css` every time you save, so new Tailwind classes take effect. Run `npm run build` again before you commit or deploy.

For a nicer workflow, use a local server such as the VS Code **Live Server** extension. The icons, fonts, and Tailwind are all local, so no internet connection is needed.

## Customize

| To change | Where |
|---|---|
| Name, email, phone, location, social links | `SITE` at the top of `js/components.js` (updates the footer on every page) |
| Navigation links | `SITE.links` in `js/components.js` |
| Icons | Shared icons: the `ICONS` list in `js/icons.js`, used as `<site-icon name="..." class="...">`. Single-use icons are inline SVGs in `js/components.js` (navbar, footer) and `about.html` |
| Colors (accent, background, badges) for light and dark mode | `:root` and `:root.dark` in `css/style.css` |
| Fonts and Tailwind color names | `@theme inline` in `css/input.css`; font imports are the `@import "@fontsource/..."` lines near the top of the same file (then run `npm run build`) |
| Page text, projects, and education entries | The matching `.html` file |
| CV | Replace `assets/cv.pdf` |
| Profile photo and project screenshots | Replace the files in `assets/images/` |

If the accent color changes, also update the favicon `fill` (`%232563eb`) in each page.

## Adding a project

Copy one `<article>` block in `projects.html`, then change the image, title, description, tech stack chips, and the two links.

## Deploy

Step-by-step instructions are in `deployment-guide.md`. In short: the site is static, so it can be hosted for free. Run `npm run build` and commit `css/tailwind.css` first (`node_modules/` stays out of the repository), so the host needs no build step:

- **GitHub Pages:** push to a GitHub repository, then turn on Pages in the repository settings (deploy from the main branch).
- **Netlify or Vercel:** drag and drop the project folder, or connect the repository.
